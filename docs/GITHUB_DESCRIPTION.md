# Suggested GitHub description

Voice-controlled MCP hardware gateway: reuse and compose skills, generate new validated programs, and control a UNIHIKER K10 through a persistent connection.

## Russian overview

Telly — экспериментальный голосовой контроллер оборудования с MCP. Он распознаёт команды, быстро запускает готовые навыки, изменяет их параметры и объединяет действия. Для новых сложных задач Codex создаёт проверяемую программу, которая сохраняется с короткой командой для повторного запуска.

Реализованы экран, светодиоды, датчики, микрофон и камера UNIHIKER K10; фото и короткие видео сохраняются без анализа содержимого. Python-программы выполняются на ноутбуке и управляют платой через ограниченный API. Голос, команды и результаты используют постоянное защищённое соединение, в том числе между изолированными сетями.

Проект полезен для прототипов роботов, учебных экспериментов и повторяемых аппаратных сценариев. Его можно расширять адаптерами оборудования. Подключение произвольного нового устройства без драйвера, подходящей электрической схемы и уже доступного интерфейса не обещается. Скорость и надёжность нужно оценивать по опубликованным измерениям; это пока прототип.
