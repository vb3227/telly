# Project rules

- Reply in the language the user writes in. Be direct and summarize tool output.
- Before changing code, choose a simple, efficient approach; validate external input and never hardcode secrets.
- Never run destructive commands or flash hardware without explicit user confirmation.
- Use subagents only for read-heavy mapping, review, or audit tasks; do not spawn more than three at once.
- Treat this project's source, `platformio.ini`, and `README.md` as its references. This repository does not currently contain `SPEC.md` or `check_fit.py`; do not assume instructions or paths from another project apply.
